# International Education Market Analysis

## Project Overview

This project was developed as part of the OpenClassrooms Data Scientist training program.

The objective is to explore international education and socioeconomic indicators to identify countries that may offer promising opportunities for educational market expansion.

## Dataset

The analysis uses World Bank EdStats datasets, including country-level educational and socioeconomic indicators.

## Methodology

The project involves:

1. Importing and exploring multiple datasets.
2. Examining data structure, quality, and available indicators.
3. Selecting relevant indicators for international market assessment.
4. Processing and combining data using Python and Pandas.
5. Constructing a composite scoring approach to compare countries.
6. Ranking potential target countries and visualizing the results.

## Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook

## Project Structure

- `Projet_2.ipynb` — Main exploratory analysis and country scoring
- `Projet_2bis.ipynb` — Additional analysis
- `revenu par habitant.png` — Supporting visualization
- `Data/` — Local datasets (excluded from Git)

## Data Source

World Bank — Education Statistics (EdStats).

## Reproducibility

The notebooks require the relevant EdStats CSV datasets to be placed in the `Data/` directory. These datasets are not included in the repository.

## Context

This project illustrates practical skills in exploratory data analysis, data preparation, indicator selection, composite scoring, and data visualization.
